# DrPaws宠物领养网站 - 后端
基于springboot+vue开发的前后端分离宠物领养网站项目，前端项目在：https://github.com/Estrellannn/DrPaws-pet-adopt-frontend

## 技术栈
Springboot、MyBatis-Plus、Spring Security、MySQL
工具：Maven、IDEA、Apifox、TiDB云数据库

## 功能说明
1.页面导航路由跳转。
2.宠物领养展示和类型筛选。
3.帖子展示和类型筛选。
4.详情弹窗预览。
5.用户的登录。

## 环境依赖
- JDK：17
- Maven：3.9.9

## 启动说明
在IDEA里运行
